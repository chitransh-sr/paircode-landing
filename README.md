# PairCode — Product Landing Page

Marketing landing page for **PairCode** (real-time collaborative code editor for technical interviews).

- **Live:** http://localhost:3001/
- **Product repo:** https://github.com/chitransh-sr/paircode-editor
- **Stack:** Next.js 16 + Tailwind CSS v4 (same theme as the app: light `#FFFFFF` / dark OLED `#0F172A`, accent `#22C55E`)

## Run it

```bash
cd paircode-landingpage
npm run dev
# → http://localhost:3001/
```

Uses `:3001` so it doesn't clash with the app on `:3000`.
